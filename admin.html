GPIO Configuration

                

                    

                        

                            
                            
                        

                        

                            
                            

                            

                        

                    

                    

                    

                        

                            
                            
                        

                        

                            
                            
                        

                    

                    

                    

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                    

                    

                        

                            
                            
                        

                        

                            
                            
                        

                        

                            
                            
                        

                    

                    

                        Relay light: turns on while a customer is inserting coins (blinks; a
                        quick flash confirms each coin). Intensity = blink tempo —
                        low is a slow pulse, high is a fast dance. Default relay pin is
                        physical pin 5 and must differ from the coin pin.
                    

                    

                        Pin numbers are PHYSICAL header pins (the numbers printed on the 40-pin header),
                        not BCM/sunxi GPIO numbers. The kernel GPIO line is shown next to each pin
                        — e.g. Orange Pi PC pin 3 = PA12 = GPIO 12.
                        Pins marked with a function (I2C/SPI/UART) only work as GPIO when that overlay is disabled.
                    

                    

                        Debounce: any edge arriving within this window after a pulse is treated as contact
                        bounce of the same coin and not counted. Recommended: 30 ms
                        (fits ≈50 ms pulse trains). If one coin double-counts, raise it; only lower
                        below 20 ms if a multi-peso coin still under-counts.
